# Route guards

Generated with `go run ./cmd/generate-openapi`. Each row records a concrete registered route containing a path parameter. Fiber middleware, HEAD mirrors and OPTIONS handlers are excluded. The OpenAPI artifact records all concrete routes.

Cross-user profile lookups return public DTOs; owners and audited staff have separate full-detail routes. Legacy private file handlers validate current app/staff sessions and local paths. Incident attachment reads retain their existing local SendFile implementation. New support ticket attachments use private storage and owner/staff-scoped reads.

Admin ride, ticket, complaint, report and rating operations are persisted and staff-audited. Dashboard operational counts use live SQL counts. Staff scope is intentionally broader than object ownership, with route roles and controller action policy enforced.
