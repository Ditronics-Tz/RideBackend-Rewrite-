# Route guards

Generated with `go run ./cmd/generate-openapi`. Each row records a concrete registered route containing a path parameter. Fiber middleware, HEAD mirrors and OPTIONS handlers are excluded. The OpenAPI artifact records all concrete routes.

The two profile lookup routes return sensitive fields to other authenticated app users. B6 must introduce public DTOs and negative privacy tests. Legacy private file handlers use controller authentication and lexical local path checks; their session/revocation consistency belongs to B5 and filesystem handling remains part of B6. Incident attachment reads have owner/staff checks but retain the existing local SendFile path handling; that existing module is outside this ship run.

Admin rides/tickets list handlers and ticket PATCH return 501 until B8 implements persisted administration workflows. Dashboard operational_counts_available=false identifies the legacy zero operational fields; driver/passenger counts are real SQL counts. Staff scope is intentionally broader than object ownership, with route roles and controller action policy enforced.
