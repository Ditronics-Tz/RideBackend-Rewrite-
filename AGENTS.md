# Shared Rida knowledge

Code-only work: do not add, modify, or run tests unless the user explicitly requests tests. Review existing test code by reading it only.

Read the workspace [shared knowledge index](<../agents/README.md>), [backend guide](<../agents/BACKEND.md>), and [known gaps](<../agents/KNOWN_GAPS.md>) before changing this repository.

The shared folder lives beside the four repositories. If this checkout is opened alone, also open the parent Rida workspace to access it. Follow the shared [AGENTS.md](../agents/AGENTS.md). Keep relevant shared documentation current when changing contracts or behavior.
